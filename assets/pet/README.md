# 콩이 그래픽 자료

## 현재: 실제 3D (2026-10-25)

- `models/`: tool/build_kongi_3d.py로 직접 생성한 아기·성장기·성체 GLB 3개. 실제 메시·재질·부위별 애니메이션(Idle/Jump/Walk/Eat)을 포함합니다.
- `scene/`: 오프라인 3D 보기의 회전·동작·의상 제어 JavaScript.
- Android에서는 이 모델을 사용합니다. 제공된 콩이 디자인을 참고한 단순화 모델이며 PNG를 정밀 복원한 결과는 아닙니다.
- 생성 소스, 검증, 설정은 docs/pet_3d.md 참고.

## 최초 제공 이미지와 대체 표시

사용자가 2026-10-24 제공한 `콩이_목업_v3`에서 필요한 54개 원본 PNG·GIF를 복사해 보존했습니다.

- baby/junior/adult: 동일 높이의 아기·성장기·성체, 사선/옆/뒤/앞 이미지와 해당 각도의 모자·니트·꽃핀 레이어(각 16개)
- items: 옷장 목록용 아이템 3개
- motion: 아기 인사/점프, 먹기/기뻐하기, 걷기 GIF 3개

WebView를 사용할 수 없는 환경 및 사용자가 명시적으로 선택한 2D 대체 보기에서 사용합니다. 최초 이미지 파일 자체에는 실제 3D 모델이 들어 있지 않았습니다.

## 홈 카드 표정 (2026-10-25)

각 성장 폴더의 greeting.png는 기존 전달본의 아기/성장기/성체_기쁨.png 원본을 그대로 복사했다. 새 홈의 웃는 캐릭터용이며 먹이 반응용 motion/happy.png(그릇 포함)와 구분한다. 옷을 입은 상태에서는 기존 의상 레이어가 유지된다.
