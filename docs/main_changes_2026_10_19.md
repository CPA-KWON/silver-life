## 기존 기능의 변경과 수정

- 하단 메뉴를 홈 / 시설 찾기 / 활동 / 동네 모임 / 커뮤니티로 구성하고, 내 정보는 홈 상단으로 이동했습니다.
- 홈은 인사·실제 활동 요약·가장 가까운 확정 일정·추천 최대 2개를 표시합니다.
- 활동과 경험 나눔의 혼합 화면을 목적별 독립 화면으로 분리했습니다. 즐겨찾기·주변 시설·내 글·내 모임은 새 진입점에서 유지합니다.
- 블루 그라데이션·실제 미션 원형 현황·둥근 카드와 버튼·짙은 하단 메뉴를 실제 앱에 적용했습니다. 목업의 예시 기록을 운영 데이터로 사용하지 않습니다.
- 네이버 지도 탭 유지·검색 중복/실패 처리·영문 기기의 한국어 지역 검색·상세 뒤로가기를 보완했습니다.
- 로그아웃 시 개인 이동 기록을 제거하고 중첩 화면에서 Android 뒤로가기가 검은 화면을 만드는 오류를 수정했습니다.
- 다른 작성자의 공개 닉네임 연결과 시설 인원 조회를 보완했습니다. 이름·출생연도 등 비공개 프로필은 공개하지 않습니다.
- 검색 비밀키를 앱에서 제거하고 인증된 서버 검색으로 옮겼습니다. 시설 수정·체크인·공개 프로필·신고 관련 권한도 보완했습니다.

## 보완 우선순위

아래는 확인된 범위에 근거한 다음 작업 제안이며, 현재 모두 구현됐다는 뜻이 아닙니다.

1. **실제 기관·모집 데이터와 운영 흐름 검증**
   - 검증 기관 외의 실제 운영 기관을 확인해 연결하고 실제 모집을 등록해야 추천·미션이 유용해집니다. 현재 기관 프로그램은 담당자가 직접 등록하며 외부 사이트에서 자동 수집하지 않습니다.
   - 일반 사용자와 기관 담당자가 다른 계정으로 신청→승인→활동 종료 후 완료→미션/이력/혜택을 운영 서버에서 확인해야 합니다. 지금까지는 이 전체 거래를 격리 DB/Android 환경에서 확인했고, 운영 서버에는 실제 타인 신청이 없어 실행하지 않았습니다.
2. **기관 담당자의 일상 업무 보완**
   - 프로그램 내용·일정 수정, 신청자 검색·상태별 필터, 결과 안내가 필요합니다. 현재 등록/마감과 개별 승인·반려·완료 중심입니다.
   - 승인·반려·모집 변경을 놓치지 않도록 사용자 알림을 추가하는 것이 유용합니다.
3. **추천과 미션의 빈 상태 안내·갱신**
   - 후보가 없는 이유와 어떤 조건을 바꾸면 되는지 안내하면 좋습니다. 반경을 임의로 늘리거나 존재하지 않는 프로그램을 만들면 안 됩니다.
   - 새 주 미션의 생성 안내 또는 자동 생성 방식을 검토해야 합니다. 기존 신청·완료 보존 규칙을 함께 유지해야 합니다.
4. **실제 이동 편의 정보**
   - 현재 거리 필터는 직선거리이고, 이동수단은 프로그램이 허용한 수단과의 일치 여부입니다. 실제 경로 거리·이동 소요시간과 이동 편의 정보를 추가하면 추천을 더 잘 판단할 수 있습니다.
5. **혜택 운영 기준 확정**
   - 기관의 참여 완료 확인 기준과 문의/오처리 대응, 할인 비용 부담 방식을 운영 측에서 정해야 합니다. 현재 온라인 결제·정산·자동 환불은 없습니다.
6. **정식 배포 준비**
   - 실제 휴대폰에서 위치 권한 거부·GPS 꺼짐·네트워크 불안정·앱 전환·장시간 사용을 추가 확인해야 합니다. 현재 최신 설치 검증은 Android 에뮬레이터/debug APK 기준입니다.
   - 배포용 서명·버전 관리와 서버 모니터링을 준비해야 합니다. 과거 공개 이력이 있는 검색키는 현재 사용자 승인으로 사용 중이며 운영용 교체는 후속 작업입니다.
