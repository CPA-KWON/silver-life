# 콩이 v3 화면 목업 (2026-10-24)

사용자 승인 범위: **화면 먼저: 시뮬레이터에서 눌러보는 목업**.

## 확인 경로

홈 → 콩이 만나러 가기 → 이름 짓기 → 함께 시작하기 → 반려동물 홈.

- 먹이 주기: 무료 기본 사료 / 임시 3P 간식 → 확인 → 먹기 반응과 완료 안내
- 옷 입히기: 모자·옷·액세서리 → 각도별 입혀보기 → 구매 확인 → 적용 / 벗기기
- 산책하기: 1,000걸음 또는 시설 도착 → 진행 상황 미리보기 2회 → 완료 보상
- 성장 기록: 이번 세션의 돌봄·활동 기록, 보유 의상, 공통 안내창 12종, 초기화
- 다른 각도 보기: 드래그 또는 사선/옆/뒤/앞 버튼
- 세 가지 성장 모습 미리보기: 아기·성장기·성체로 임시 경험치 직접 변경
- 오늘의 활동: 임시 출석, 기존 주간 미션 세 단계 연결 설명, 가상 프로그램 신청→승인→참여 완료→보상, 광고 완료 상황

하단 5개 탭은 반려동물 화면에서도 유지합니다. 홈과 활동은 각각 독립 이동 이력을 보관합니다. 시설 지도는 기존 RetainedMapTab을 유지합니다. 홈으로 탭을 바꾸면 실제 활동 요약을 다시 읽습니다. 로그아웃 시 MainShell과 임시 데이터가 폐기됩니다.

## 실제 기능과의 경계

반려동물 전용 상태는 PetPreviewController의 메모리에만 있습니다. Supabase·실제 출석·포인트 지갑·기관 신청을 호출하거나 변경하지 않습니다. 실제 광고 SDK·위치·걸음 수 권한도 요청하지 않습니다. 기존 홈 요약·프로필·다른 탭은 원래 서버 기능을 계속 사용합니다.

이름·임시 포인트·의상·기록은 앱 프로세스 재시작 또는 로그아웃 시 초기화됩니다. 서버 저장, 날짜 변경, 실제 미션 동기화, 결제, 운영 보상 부정 방지는 구현하지 않았습니다. 공통 안내창 모음의 오류/처리 중/광고 상태는 디자인 예시입니다.

## 임시 수치

시작 20P. 출석 +1P/+5XP, 첫 먹이 +5XP(추가 먹이 성장 없음), 산책 +2P/+10XP, 가상 기관 완료 +5P/+30XP, 광고 +1P·최대 2회·XP 없음. 반복 활동/참여 완료 보상은 세션당 한 번. 꽃핀 5P, 모자 10P, 니트 20P. 의상 구매로 XP는 늘지 않습니다.

아기 0XP → 성장기 150XP → 성체 600XP. 단계 미리보기 버튼은 XP를 직접 바꾸는 검토용 도구이며 운영 기능이 아닙니다. 목업 이미지의 큰 포인트 수치를 실제 잔액으로 표시하지 않습니다.
