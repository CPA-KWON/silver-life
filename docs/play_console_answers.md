# Play Console 답변표 (첫 출시 기준)

2026-10-31 코드 기준 초안이다. Play Console의 질문 문구는 바뀔 수 있으니 화면을 보고 확인한다. 법률 검토를 대신하지 않는다.

**전제:** 유료 구매 끔, 광고 버튼 숨김(운영 광고 단위 없음), 휴대폰 인증 숨김, 산책 포그라운드 서비스 없음. 나중에 켜면 아래 "기능을 켤 때 바꿀 답"대로 고친다.

## 앱 콘텐츠

| 질문 | 답 | 근거 |
|---|---|---|
| 개인정보처리방침 | 공개 URL 입력 | `docs/privacy-policy.html`을 공개한 주소 |
| 광고 포함 | **아니요** | 첫 출시 빌드에는 광고가 나오지 않는다 |
| 광고 ID 사용 | **예 → 용도: 광고 또는 마케팅** (아래 결정 사항 참고) | AdMob 라이브러리가 `AD_ID` 권한을 넣는다 |
| 앱 액세스 권한 | **일부 기능 제한 → 심사용 계정 제공** | 로그인이 필요하다. 테스트 계정 이메일·비밀번호를 적는다 |
| 타겟층 | **18세 이상** | 50~70대 대상. 아동 대상이 아니다 |
| 뉴스 앱 / 정부 앱 / 금융 기능 | **아니요** | |
| 건강 앱 | **아니요** (아래 메모 참고) | 걸음 수는 반려동물 놀이용이고 건강 관리 기능이 아니다 |
| 포그라운드 서비스 권한 | **해당 없음** | 최종 앱에 권한이 없다 |
| 사진·동영상 권한 | **해당 없음** | 시스템 사진 선택기를 쓴다. 제출 화면에 질문이 뜨면 다시 확인한다 |
| 계정 삭제 | **예 → URL 입력** | https://cpa-kwon.github.io/silver-life/account-deletion.html |

| 질문 | 답 | 근거 |

| 사용자 위치를 다른 사용자와 공유 | **예** | 친구 체크인 공유(기본 꺼짐, 시설 이름과 시간) |

## 데이터 보안: 데이터 유형

수집 = 기기 밖으로 보내는 것. 저장하지 않아도 보내면 수집이다.

| 유형 | 수집 | 공유 | 필수/선택 | 목적 | 어디서 |
|---|---|---|---|---|---|
| 위치 > 정확한 위치 | 예 | 아니요 | 선택 | 앱 기능 | 시설 찾기, 체크인, 산책, 활동 기준 장소 |
| 개인 정보 > 이름 | 예 | 아니요 | 필수 | 앱 기능, 계정 관리 | 회원가입 |
| 개인 정보 > 이메일 | 예 | 아니요 | 필수 | 계정 관리 | 회원가입 |
| 개인 정보 > 사용자 ID | 예 | 아니요 | 필수 | 앱 기능, 계정 관리 | 계정, 닉네임 |
| 개인 정보 > 전화번호 | 예 | 아니요 | 선택 | 앱 기능 | 기관 담당자 연락처 |
| 개인 정보 > 기타 | 예 | 아니요 | 필수 | 앱 기능 | 출생연도, 거주 지역, 재직 확인 자료 |
| 사진 및 동영상 > 사진 | 예 | 아니요 | 선택 | 앱 기능 | 글·모임·프로필 사진, 재직 확인 자료 |
| 건강 및 피트니스 > 피트니스 | 예 | 아니요 | 선택 | 앱 기능 | 산책 걸음 수 |
| 앱 활동 > 앱 상호작용 | 예 | 아니요 | 필수 | 앱 기능 | 출석, 포인트, 참여, 신고, 차단, 친구 |
| 앱 활동 > 기타 사용자 제작 콘텐츠 | 예 | 아니요 | 선택 | 앱 기능 | 글, 댓글, 모임 |
| 재무 정보 | 아니요 | | | | 유료 구매 꺼짐 |
| 메시지, 연락처, 파일, 캘린더, 오디오, 웹 기록 | 아니요 | | | | 비상 연락처는 기기에만 저장 |

위치는 대부분 저장하지 않지만 활동 기준 장소는 저장하므로 "임시 처리"로 표시하지 않는다.

제출 전 Google Play SDK Index와 AdMob, Naver Map SDK의 데이터 안내를 확인한다. SDK가 스스로 보내는 진단·기기 정보가 있으면 위 표에 더해야 한다. **이 표는 앱 코드 기준이며 SDK 내부 동작까지 확인한 것은 아니다.**

## 결정이 필요한 것

1. **광고 ID:** 첫 출시에 광고가 없는데 라이브러리 때문에 `AD_ID` 권한이 들어 있다. `AndroidManifest.xml`에 `<uses-permission android:name="com.google.android.gms.permission.AD_ID" tools:node="remove"/>`를 넣어 빼면 "광고 ID 사용: 아니요"로 답할 수 있다. 광고를 켤 때 다시 넣어야 한다.
2. **건강 앱:** 걸음 수를 다루므로 심사에서 질문받을 수 있다. 신체 활동 권한을 왜 쓰는지 "반려동물과 산책 기록"으로 설명한다.

## 기능을 켤 때 바꿀 답

| 켜는 기능 | 바꿀 답 |
|---|---|
| 광고 | 광고 포함 **예**, 광고 ID 사용 **예**, 기기 ID > 광고 ID 수집 **예**(공유 **예**, 목적: 광고), 위치·앱 활동의 광고 목적 공유 여부를 AdMob 안내대로 수정. 빌드에 `SILVER_LIFE_ADMOB_APP_ID`, 광고 단위, `ATTENDANCE_ADS_LIVE=true` 필요(지금 빌드의 앱 ID는 Google 테스트 ID) |
| 유료 구매 | 디지털 상품 구매 **예**, 재무 정보 > 구매 내역 수집 **예**, Play 상품 등록, `ENABLE_PAID_ITEMS=true` |
| 휴대폰 인증 | 전화번호를 **필수/선택에 맞게** 수정, 문자 발송 업체를 위탁 업체에 추가 |
| 백그라운드 산책 | `docs/pet_walk_background.md` 참고. 포그라운드 서비스 권한 신고서와 시연 영상 필요 |
