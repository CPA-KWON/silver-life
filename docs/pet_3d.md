# 콩이 실제 3D 구현 (2026-10-25)

사용자 요청에 따라 기존 이미지 목업을 **실제 GLB 메시 모델**로 확장했습니다. 포인트·활동·광고의 임시 데이터 범위는 유지합니다.

## 사용 방법

홈 → 콩이 만나러 가기 → 이름 짓기 → 함께 시작하기.

- 반려동물 홈: 손가락으로 캐릭터를 좌우로 연속 회전. 들어올 때 점프한 뒤 숨쉬기·꼬리 흔들기.
- 좌우로 돌리기: 큰 보기 창에서 좌우 회전 또는 사선/옆/뒤/앞 버튼. 카메라 높이(80도)와 거리를 고정해 위아래로 기울어지지 않게 합니다. 이 제한은 홈과 옷장에도 공통 적용합니다.
- 먹이 주기: 입체 머리·꼬리의 먹기 반응. 완료 후 대기 동작 복귀.
- 옷 입히기: 모자·니트·꽃핀을 3D 파츠로 입혀보고 회전. 구매·착용 규칙은 기존 임시 지갑을 사용.
- 산책: 기존 임시 진행 화면에서 다리·팔·몸의 걷기 동작.
- 세 가지 성장 모습 미리보기: 아기·성장기·성체 GLB 교체. 성장할수록 몸통이 길어지고 머리와 몸의 비율이 바뀜.

## 모델과 렌더링

- `tool/build_kongi_3d.py`: 원본 생성 소스. Python 표준 라이브러리만 사용하며 Blender 설치 불필요. 동일 명령으로 재생성 가능.
- `assets/pet/models/{baby,junior,adult}.glb`: 메시·재질·부위별 노드·애니메이션을 담은 독립 glTF 2.0 바이너리. 3개 합계 약 452KiB.
- 직접 만든 단순화 모델로, 제공 PNG를 평면에 붙여 돌리는 방식이 아닙니다. 원본 디자인의 둥근 머리·갈색 귀·파란 목걸이·연한 배·분홍 볼을 참고했습니다. 원본 사진을 정밀하게 복원한 모델은 아닙니다.
- 노드 애니메이션 `Idle`, `Jump`, `Walk`, `Eat`. 의상은 머리·몸에 연결된 메시여서 회전과 동작을 함께 따라갑니다.
- `model_viewer_plus 1.10.0`의 번들 Google model-viewer + 네이티브 WebView. GLB와 JavaScript는 APK에 포함되어 외부 모델 서버·CDN·키가 필요 없습니다.
- `assets/pet/scene/kongi_scene.js`: Flutter와 실제 브라우저 검사에서 공유하는 재생·카메라·의상 제어.
- animationName 반영 완료 후 유한 횟수로 점프/먹기를 재생합니다. 중복 속성 갱신이 동작을 무한 반복으로 바꾸지 않도록 처리했습니다.

## 상태·실패 처리

- 홈/다른 탭과 화면 이동 중 3D 보기를 유지하고, 숨겨진 화면과 앱 백그라운드에서는 동작을 멈춥니다. 카메라 방향은 뷰가 유지되는 동안 보존합니다.
- 기기의 동작 줄이기 설정에서는 애니메이션을 재생하지 않습니다. 직접 회전과 방향 버튼은 사용할 수 있습니다.
- 로딩 안내, 모델 오류/25초 초과 시 재시도와 명시적 ‘2D 이미지로 보기’를 제공합니다. 2D 대체는 기존 의상 레이어도 표시합니다.
- Android/iOS용 뷰어입니다. WebView를 사용할 수 없는 테스트/데스크톱 환경에서는 기존 이미지 경로를 사용합니다.
- Android HTTP 예외는 `localhost`·`127.0.0.1`에만 허용하며 원격 HTTP 허용은 확대하지 않았습니다. 앱 내부의 번들 파일 전달용입니다. 기존 Flutter 최소 Android API 24를 유지했습니다.
- iOS 로컬 네트워크 설정은 추가했으나 iOS 기기 실행은 이번에 검증하지 않았습니다.

## 검증 결과

- Khronos glTF Validator 2.0.0-dev.3.10: 세 GLB 모두 오류 0·경고 0.
- 실제 WebGL 검사: 외부 네트워크 차단 상태에서 3개 모델 로딩, 4개 클립, 드래그 카메라 이동, 7개 의상 재질 켜기/끄기, 점프 완료 → Idle 복귀, 동작 줄이기 일시정지 확인.
- Flutter: 정적 검사 문제 없음, 기존 기능 및 GLB 구조·점프 착지 포함 자동 검사 95개 통과.
- Android Pixel_10a: 실제 3D 표시·드래그·방향 버튼·옷장 및 탭 이동 수동 확인. 앱 내부 재생 상태에서 Jump 완료 후 Idle, 같은 뷰 ID·카메라 방향 유지, 비활성 탭/앱 백그라운드 일시정지와 복귀 재개를 확인했습니다. 실제 휴대폰의 성능은 별도 확인 대상입니다.

Supabase·RLS·실제 출석·포인트·기관·광고 SDK는 수정하거나 연결하지 않았습니다. main 병합·GitHub push도 하지 않습니다.
