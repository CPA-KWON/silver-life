## 사용 방법과 범위

ins 로그인 → 홈 상단 내 정보 → 기관 관리.
기관 운영에서 실제 프로그램을 등록하면 사용자 목록·추천의 후보가 됨.
검증 기관은 실제 복지관을 사칭하지 않는 검증용 기관이며 실제 기관·담당자는 관리자 검토 후 연결.
프로그램이 없거나 조건에 맞지 않으면 추천·미션은 비어 있을 수 있음.
거리는 직선거리, 시간은 프로그램 길이 조건이며 도보·차량 길찾기 시간은 제공하지 않음.
주간 미션 생성/새로고침은 사용자가 실행해야 함.
카드 결제·정산·푸시·동행 매칭·기관 신청 검색/필터·프로그램 편집 UI는 현재 범위에 포함되지 않음.

비밀 설정·세션·APK는 git 제외. 커밋은 로컬에 보관하고 GitHub 업로드 전 사용자 확인.

## 시설 화면 후속 수정 (2026-10-18)

- 검색 서버 키 미설정(503)을 인터넷 장애로 표시하던 오류 수정. 준비 중 안내와 `경로당 보기` 버튼 제공. 로그인 만료·요청 제한·실제 통신 실패는 각각 구분.
- 새 검색 전에 이전 분류의 마커 제거. 약국 검색 실패 후 경로당 마커가 남는 혼동 해결.
- 홈에서 연 시설 상세는 상단 `시설찾기`의 뒤로가기 화살표 하나만 표시. 지도 탭에서 연 상세의 자체 뒤로가기는 유지.
- Pixel_10a 에뮬레이터의 실제 운영 연결 앱에서 경로당→약국(준비 중, 이전 마커 제거)→경로당 복귀, 홈 시설 상세의 화살표 하나, 상세 닫기→홈 복귀 확인.
- 위 시설 화면 수정 당시에는 키 작업이 보류였으며, 같은 날 이후 사용자 재개 승인으로 기존 키의 서버 등록과 검색 응답 확인을 완료했습니다.
