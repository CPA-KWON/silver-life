# 활동 메인 목업 반영 (2026-10-27)

기준 main: `7445cdc`. 로컬 작업 브랜치 `feat/activity-hub-mockup`. main 병합·push는 하지 않는다.
사용자 제공 `01_활동_전체스크롤.png`를 기준으로 검색/미션/나의 활동/경험 나눔/콩이 연결을 재구성했다.

## 연결

| 진입점 | 기존 목적지 / 데이터 |
| --- | --- |
| 상단 별 포인트 | AttendanceScope 공통 지갑·출석 달력. 닫은 뒤 기존 콩이 출석 동기화 |
| 맞춤 활동 찾기 제목 | 기존 추천 조건·맞춤 결과·전체 프로그램 연결 |
| 검색어 + 화살표/키보드 검색 | 모집 중 전체 프로그램에서 제목·설명·기관·장소·분야 검색 |
| 운동 / 건강 | 기존 건강·운동 분야 필터 |
| 취미 | 문화·취미 분야 필터 |
| 교육 | 배움·디지털 분야 필터 |
| 주간 미션 카드 | 사용자 확인에 따라 콩이 출석/함께 활동/프로그램 미션 전용 보기 |
| 전용 보기의 프로그램별 주간 미션 보기 | 기존 익숙한 동네/새로운 장소/함께 활동 프로그램별 미션 생성·다시 고르기 |
| 나의 활동 | 기존 신청 내역·참여 이력·혜택 |
| 경험 나눔 | 내 경험 관리·모집 탐색·지원 현황 |
| 콩이 배너 | 홈의 같은 반려동물 진입점. 중복 경로를 쌓지 않고 홈 Navigator 재사용 |

검색/필터는 기존 `activity_home`이 제공하는 모집 중 프로그램에 적용한다. 새 API·SQL·RLS 변경은 없다.
새 카테고리를 서버에 추가하지 않아 ‘운동’과 ‘건강’은 같은 기존 분야에 매핑된다.

콩이 미션 요약은 MainShell의 동일한 PetPreviewController를 사용한다. 예시 1/3을 고정하지 않으며 수령한 단계 수를 표시한다. 미로딩·실패 상태는 진행률을 추측하지 않고 확인 중/다시 확인으로 보여준다.
‘함께 활동’ 실적은 기존 서버의 함께 참여 기관 프로그램 완료 기준이다. 일반 동네 모임에 참여 완료 기록이 생긴 것처럼 표시하지 않는다.

`PetTodayPage.missionsOnly`는 기존 보상 로직으로 출석·주간 미션만 표시하고 광고·프로그램 보상 섹션은 숨긴다. 반려동물 미입양/서버 실패 안내와 기존 프로그램 미션 진입을 제공한다. 기존 콩이 오늘의 활동 전체 화면은 유지한다.

- 전체 Flutter 테스트 125개 통과: 검색어·분야 실제 결과 반영, 미션 공유 상태, 오류·미입양, 기존 미션 보존, 공통 지갑, 지도 요소 유지, 320dp 글자 200% 포함.
- flutter analyze: 문제 없음.
- Android arm64 debug 빌드 성공. 최종 네이티브 확인 완료.
- 후속 목업 요청은 활동 메인과 연결되는 8개 화면 묶음(추천·목록·상세·콩이 미션·기존 미션·나의 활동·경험 나눔·공통 상태)을 기준으로 정리했다.

## Android 수동 확인

- 기존 ins 로그인과 실제 지갑 1P/미션 0/3을 유지한 채 설치.
- 활동 메인 상·하단, 교육 분야 필터, 콩이 주간 미션, 기존 프로그램별 미션, 나의 활동, 경험 나눔, 콩이 배너→기존 홈 이동 확인.
- 해당 계정의 모집 목록·신청 내역이 없는 경우 실제 빈 상태 표시. 캡처를 위해 프로그램이나 신청·포인트를 만들지 않음.
- 결과 스크린샷과 디자이너 요청문은 작업 공간 outputs/activity-mockup-20261027에 별도 보관. Git에는 앱 소스·검증·문서만 저장.
