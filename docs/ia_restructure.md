## 기본 구조

하단: 홈 / 시설 찾기 / 활동 / 동네 모임 / 커뮤니티.
내 정보는 홈 상단 버튼에서 진입합니다. 기관 담당자 계정에만 내 정보의 기관 관리 진입점이 표시됩니다.

- 홈: 인사, 이번 주 예정 활동·미션 완료 요약, 가장 가까운 확정 예정 활동, 추천 최대 2개.
  - 예정 활동은 본인의 승인된 신청 중 미래 일정입니다. 일반 공개 모임을 본인 신청인 것처럼 표시하지 않습니다.
  - 이번 주는 기기의 현지 월요일~일요일입니다. 서버 미션은 기존 Asia/Seoul 주간 기준을 유지합니다.
- 시설 찾기: 기존 유지 지도, 검색·필터·시설 상세·전화·즐겨찾기·체크인·시설 모임.
  - 주변 시설 목록은 이 메뉴 상단 `주변 시설`에서 사용합니다.
  - 시설 상세의 `이 시설의 프로그램`은 기존 활동 목록 API의 시설명과 저장 좌표 100m 이내 조건으로 연결합니다. 일반 프로그램과 경험 나눔 모집 모두 포함합니다.
  - 즐겨찾기에서 현재 거리 정보가 없으면 0km를 표시하지 않습니다.
- 활동: 아래 네 화면의 진입점만 배치합니다. 가로 탭·좌우 페이지 넘김을 제거했습니다.
  - 맞춤 활동 찾기 → 추천 조건 설정 / 추천 결과 / 전체 프로그램 탐색 → 공통 활동 안내.
  - 주간 미션 → 진행 요약 / 기존 3단계 카드 / 생성·미신청 다시 고르기. 추천 결과 목록은 배치하지 않습니다.
  - 나의 활동 → `보기` 선택 목록으로 신청 내역 / 참여 이력 / 혜택을 한 번에 하나씩 표시합니다. 완료 외 취소·반려를 포함한 상태는 신청 내역에 남깁니다.
  - 경험 나눔 → 내 경험 관리 / 기관 모집 탐색 / 지원 현황의 독립 화면. 내 경험 목록이 모집 목록을 아래로 밀지 않습니다.
- 동네 모임: 기존 모임 목록·상세·만들기, 상단 `내가 만든 모임` → 기존 본인 작성 모임 목록.
- 커뮤니티: 기존 글·분류·지역·댓글·작성·수정·삭제·신고 유지.
- 내 정보: 프로필 / 나의 활동 / 내가 쓴 게시글 / 내가 만든 모임 / 즐겨찾는 시설 / 기관 관리(담당자) / 회원정보 관리 / 개인정보 처리방침 / 로그아웃.
  - 나의 활동은 위 활동 메뉴와 같은 화면을 재사용합니다.
  - 회원정보 수정과 로그아웃은 기존 기능을 재사용합니다. 로그아웃 확인 처리는 두 진입점에서 공통 함수를 호출합니다.

## 이동과 데이터 보호

- 활동 전용 화면은 하단 메뉴를 유지하는 내부 Navigator에서 열립니다. 다른 탭으로 갔다 와도 활동의 직전 화면이 유지됩니다.
- 홈의 추천·나의 활동 진입도 동일 활동 내부 Navigator로 연결합니다.
- 기존 네이버 지도는 `RetainedMapTab`을 유지하여 최초 방문 때 생성하고 탭 재방문 때 재생성하지 않습니다. GPS 활성 여부는 시설 탭 선택 상태를 사용합니다.
- Android 뒤로가기는 상위 세션 Navigator의 `maybePop`으로 하위 화면의 처리 규칙을 존중합니다. 루트 강제 pop으로 검은 화면이 생기는 오류를 재현 검사로 보완했습니다.
- 비활성 활동 탭은 다른 화면의 뒤로가기 요청으로 자신의 화면을 pop하지 않습니다.
- 기존 AuthGate의 사용자별 Navigator 교체는 유지하여 로그아웃 시 개인 화면·이동 이력을 제거합니다.
- SQL·테이블·RLS·신청/혜택 계산 API는 변경하지 않았습니다. 새 표시에도 기존 인증 API만 사용합니다.
- 이번 실제 화면 검사에서는 모집·신청·경험·미션을 새로 저장하지 않습니다. 데이터가 있을 때의 저장·신청·승인 등은 대체 저장소를 사용하는 기존 동작 검사로 확인합니다.
