# 2026-10-25 main 통합 범위

사용자가 지금까지 개발한 내용을 팀 저장소 main에 push하도록 명시 승인했다.
대상: CPA-KWON/silver-life. 이전 main은 `2950ae9`, 개발 코드 기준은 `8358a7b`.
기존 main의 후속 개발이 없는 상태에서 전체 커밋을 이력 그대로 fast-forward 통합한다.

## 포함된 개발

- 새 홈 목업: 날짜/포인트/프로필, 출석 카드와 실제 주간 기록, 원본 표정의 콩이 카드, 모임/기관 공지/커뮤니티, 맞춤 활동/즐겨찾기 진입.
- 콩이: 입양·이름·먹이/간식·의상 구매/착용·3단계 성장·성장 기록/달력·오늘의 활동. 실제 Supabase 저장, 지갑 공유, 하루 한 번 출석 경험치와 기관 참여 완료 보상 검증.
- 원본 PNG/의상 레이어와 별도 GLB 3단계/Idle·Jump·Walk·Eat 동작. 3D 카메라는 좌우 회전으로 제한. 원본 3D 파일이 없어 GLB 외형은 제공 PNG와 완전히 같지는 않다.
- Android 걸음/GPS 포그라운드 서비스, 진행 상태 보존·산책 보상 API 및 제한 검사.
- Google Mobile Ads SDK, 광고 보상 서버 서명 검증 소스와 위조/중복 차단. 실 운영 연결은 아래 후속 작업 참조.
- 기관 공지: 승인된 담당자만 자기 기관의 공지를 저장/수정/게시/중지. 지역 홈 및 상세/목록, 선택 원문/게시 종료일. 비공개·만료·다른 기관 접근 차단.
- 로그인 갱신의 일시적인 네트워크 오류 처리. 기존 로그아웃 시 개인 화면 제거와 지도 유지 구조를 보존.

## 검증

- Flutter 전체 테스트 113개 통과, 정적 검사 지적 없음, Android arm64 debug APK 빌드 성공.
- 격리 PostgreSQL에서 반려동물 및 공지 SQL 설치/재실행, 중복 보상/잔액 부족 롤백, 기관 소유권/RLS/익명 접근 제한 검증.
- 광고 서명 검증 소스의 ECDSA 정상·변조·중복 파라미터·만료 테스트.
- 실제 운영 API에서 콩이 저장/재로그인 보존, 공지 비공개 저장·수정/재로그인 보존, 위조 및 직접 쓰기 제한 확인. 새 홈과 출석 달력은 Android에서 실제 계정으로 확인.
- `.env.json`, 관리자 비밀키, 서명 파일, APK는 커밋하지 않는다. 공개 프로젝트 주소/서버 함수 경로는 설정 문서에 포함한다.

## 별도 후속 작업

- AdMob 운영 앱/광고 단위 설정과 SSV 함수 배포·실제 Google 콜백 검증.
- 실물 Android에서 화면 꺼짐/절전/위치 권한/걸음 센서 검증.
- 레인코트 착용·성체 전용 산책 코스는 자료 부재로 준비 중. 겨울 니트 외형은 임시 색 변환.
- 원본과 동일한 품질의 3D 의상/동작 추가 제작, 실제 기관 프로그램 확보 및 운영 사용자 전체 거래 검증.
- 회의에서 제안한 참여 조건 도우미·실내 사진 길잡이·안심번호·트로트는 아직 구현하지 않았다.

GitHub main 코드 반영은 앱스토어 출시, APK 정식 배포, 광고 수익화 완료를 뜻하지 않는다.
